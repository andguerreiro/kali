LAB QEMU/KVM - DEBIAN 13 + KALI + WINDOWS 7
============================================================

DATE: 19/08/2026

OBJECTIVE
---------
Create an isolated local lab on Debian 13.6 + XFCE,
using QEMU/KVM, with two virtual machines:

- Kali Linux 2026.2 QEMU AMD64
- Windows 7 Starter SP1 32-bit

Lab objectives:
- Kali as the testing machine
- Windows 7 as the target machine
- Communication between the VMs
- No Internet access for the VMs
- No exposure of the VMs to the host's physical LAN
