# Lab04 — Windows 7 Firewall and Network Isolation Lab

## Overview

Lab04 is a controlled virtualization lab designed to reproduce the Windows 7 network-security experiments from the previous labs, but using **Fedora Workstation as the host** instead of Kali Linux.

The goal is to use Fedora directly as the testing machine, with tools such as Nmap and Metasploit, while keeping the Windows 7 guest inside an isolated virtual network.

The lab is intended to investigate how Windows Firewall configuration affects network exposure and exploitability.

> **Safety:** This lab is intended for an isolated, authorized environment. The Windows 7 VM must not be connected to an untrusted network or the Internet during testing.

---

## Lab Architecture

```text
                         Fedora 44 Workstation
                         Host
                              |
                              |
                +-------------+-------------+
                |                           |
         wlp11s0f3u1                    virbr10
         192.168.15.104                10.10.10.1
                |                           |
         Physical/LAN                  lab-isolated
                                            |
                                            |
                                      Windows 7 VM
                                      lab04-win7
                                      DHCP: 10.10.10.100-200
```

The Windows 7 VM has a single virtual network interface connected to `lab-isolated`.

The `lab-isolated` network has no `<forward>` element in its libvirt definition, so it is not configured as a NAT network or bridged onto the physical LAN.

# 4. Isolated Libvirt Network

## Network Name

```text
lab-isolated
```

## Network Parameters

```text
Bridge:       virbr10
Host IP:      10.10.10.1/24
DHCP range:   10.10.10.100 - 10.10.10.200
```

The network XML was created as:

```xml
<network>
  <name>lab-isolated</name>
  <bridge name='virbr10' stp='on' delay='0'/>
  <ip address='10.10.10.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='10.10.10.100' end='10.10.10.200'/>
    </dhcp>
  </ip>
</network>
```

The definition was registered with:

```bash
sudo virsh -c qemu:///system net-define /tmp/lab-isolated.xml
```

Result:

```text
Network lab-isolated defined from /tmp/lab-isolated.xml
```

The network was started with:

```bash
sudo virsh -c qemu:///system net-start lab-isolated
```

Result:

```text
Network lab-isolated started
```

Autostart was enabled:

```bash
sudo virsh -c qemu:///system net-autostart lab-isolated
```

Result:

```text
Network lab-isolated marked as autostarted
```

Bridge:




```text

10.10.10.100 dev virbr10 src 10.10.10.1
```

This confirms that the physical LAN and the lab network use different interfaces.

```xml

  <name>lab-isolated</name>
  <uuid>bf683535-9e62-4023-920a-8959b9816ef7</uuid>
```

Notably, there is no `<forward>` element.

```bash
  --connect qemu:///system \
  --name lab04-win7 \
  --memory 2048 \
  --vcpus 2 \
  --os-variant win7 \
  --boot loader=/usr/share/seabios/bios.bin,loader.readonly=yes \
  --disk path=/var/lib/libvirt/images/lab04-win7.qcow2,format=qcow2,bus=sata \
  --cdrom /var/lib/libvirt/images/pt_windows_7_professional_with_sp1_x64_dvd_u_676950.iso \
  --network network=lab-isolated,model=e1000 \
  --graphics spice \
  --video qxl
```

# 14. Next Experimental Steps

The next stage should establish a baseline before any exploitation attempt.

Planned sequence:

1. Determine the Windows 7 DHCP address.
2. Confirm Fedora → Windows 7 connectivity.
3. Confirm Windows 7 does not have Internet/LAN access through the isolated network.
4. Record the Windows 7 network configuration.
5. Record the Windows Firewall state/profile.
6. From Fedora, perform service discovery against the Windows 7 VM.
7. Install/configure Nmap and Metasploit on Fedora if necessary.
8. Establish a baseline of exposed services and ports.
9. Perform the controlled Lab04 security test.
10. Compare the results with Labs 01–03.
11. Repeat under different Windows Firewall profiles where appropriate.
12. Document which network services become reachable or blocked under each profile.

The key experimental variable should be the **Windows Firewall configuration**, while keeping the VM, network topology, and attacker host otherwise unchanged.

---

# 15. Important Isolation Principle

The Lab04 network should remain isolated throughout the security testing.

The Windows 7 VM should have:

```text
ONLY:
lab-isolated → virbr10 → 10.10.10.0/24
```

It should NOT be connected to:

```text
192.168.15.0/24
```

and should not receive Internet access through a second NAT interface.

This isolation is important because Windows 7 is an obsolete operating system and the purpose of this experiment is to study network exposure in a controlled environment.
