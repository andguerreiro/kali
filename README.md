# Kali Linux Labs

## lab01

### Objective

Set up an isolated virtual environment where **Kali Linux is used as the attack machine** and **Windows 7 is the target**. The lab enables controlled penetration-testing exercises between the two VMs while keeping them isolated from the Internet and the physical network.

## Hardware
- 5700X
- RX 7600
- 16GB DDR4
- 512GB KC3000
- CF-WU785AC
